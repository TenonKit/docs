## .tenon

A whole project in one file. Double-click it to open the project in Tenonkit. Made with **Export project file**.

## .tenontheme

A theme, as JSON. Double-click it to install it. See [Themes](/builder/themes#theme-files) for the format.

## Older files

Files from when Tenonkit was called Redesign, `.redesign` and `.rdtheme`, still open.
