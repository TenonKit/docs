## Websites and components

A **website** is a page built from components. A **component** is one reusable piece, written in HTML or React. Every component project shows up under **My components** in all your websites.

**Save as component** turns any block on a page into its own component project.

<Figure src="projects-light.png" alt="Home showing project cards" />

## Where projects live

Projects are folders on your computer, in `%APPDATA%\Tenonkit\projects`.

## Sharing a project

Use **Export project file** on a project’s card. You get a `.tenon` file that anyone can double-click to open in Tenonkit. Opening the same file twice doesn’t make a copy.
