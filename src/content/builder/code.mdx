HTML components show their markup; React components show **JSX**. The page re-renders as you type.

## React components

A React component exports itself as the default and can import from `react` only:

```Counter.jsx
import { useState } from 'react'

export default function Counter() {
  const [n, setN] = useState(0)
  return <button onClick={() => setN(n + 1)}>Clicked {n} times</button>
}
```
