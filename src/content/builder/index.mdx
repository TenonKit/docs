You build a page by dropping in **components**: a hero, a pricing table, a footer. Change them with the **Design** tab, or open their HTML, JSX and CSS and edit the code directly. When you’re done, export one HTML file or a React project.

## Everything stays local

Tenonkit needs no account and no cloud. Your projects are files on your computer, and the only thing the app sends on its own is a check for updates. See [Privacy](https://tenonkit.com/privacy) for the details.
